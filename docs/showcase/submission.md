# CourseWorks Secretary — Your Coursework, in View

Project URL: https://github.com/jianyangg/courseworks-secretary-public

Preview: [courseworks-secretary-preview.png](courseworks-secretary-preview.png)

## Description

I built CourseWorks Secretary because deadlines and instructions were scattered across course pages, announcements, and syllabi. It brings coursework into a timeline, calendar, graded-work list, and exam/project overview, with links to the sources. I used Codex to build and refine the app and review materials for my private guide. The public repo lets students run their own copy and extend it with their AI coding assistant.
