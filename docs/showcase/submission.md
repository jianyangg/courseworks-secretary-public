# CourseWorks Secretary — Your Coursework, in View

Project URL: https://github.com/jianyangg/courseworks-secretary-public

Preview: [courseworks-secretary-preview.png](courseworks-secretary-preview.png)

## Description

I built CourseWorks Secretary to stop hunting across course pages, announcements, and syllabi. It puts deadlines, graded work, and exams in one timeline and calendar. I used Codex to build the app and study course sources, distilling grading rules, submission requirements, and key instructions into a private course guide. Students can run their own copy and extend it with their coding assistant.
