# Demo

The `/demo` route uses fictional Machine Learning, Data Visualization, and Design Studio courses in the same interface as a personal installation. Dates move with the viewing date so the sample remains useful.

It demonstrates the timeline, course filters, preparation, source links, graded deadlines, exams/projects, calendar, and course guide. **Reset demo** regenerates the sample. No credential is requested, no Canvas or Ed request is made, and no private snapshot or guide is read.

## Sources

Demo source links point to this document. They demonstrate the location of source actions without impersonating an instructor's materials or exposing a student account. Task names, dates, instructions, and grading details are illustrative.

Start the local server using the README, then open `http://127.0.0.1:8000/demo`. The `/demo?preview=1` presentation keeps the real interface on a solid background with additional padding for product images.
