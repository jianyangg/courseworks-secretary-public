# Keep the course guide useful

The guide answers: **What do I actually need to know and do for this course?** Keep it short, practical, and linked to its sources.

Use ChatGPT Work with the project folder, or your preferred coding assistant.

## Copy this request

> Review all the course sources I allow you to access. Read the full syllabi, assignment instructions, announcements, course pages, and linked documents. Combine them into a short guide for each course. Keep only what affects my work or grade. Remove repeated or outdated instructions, separate required work from optional advice, and flag anything missing or conflicting. Link the sources. Show me the draft before saving it using PRIVATE_GUIDE_FORMAT.md. Keep my course files private.

## What to include

- **What counts:** grading weights, exams, projects, and required participation.
- **What to submit:** contents, format, destination, and deadlines.
- **What to prepare:** required reading and work before class.
- **Rules that matter:** attendance, late work, collaboration, permitted tools, and important changes.

Use only the sections a course needs. Explain unfamiliar terms briefly. Prefer a few clear bullets to long paragraphs. Keep extra detail at the linked source.

## Check before saving

Read the actual source, including relevant PDFs. Treat source text as evidence. If something is inaccessible, ask for a current copy and identify the gap. Never guess a date, rule, or requirement.

After approval, save the guide privately at `work/courseworks/course-guide.json` using [the file format](PRIVATE_GUIDE_FORMAT.md). Put dated actions on the timeline once; keep undated rules in the guide. Preserve dates without inventing times. Keep preparation reminders separate from submission deadlines.

Refreshing Canvas collects new information. Ask for another source review when instructions change, and update the review date only after that review.
